# Colors

Brand color palette pulled from Figma: [AIA - Component Library](https://www.figma.com/design/j6l3kRxBQRNGbf3cwR9NZq/AIA---Component-Library?node-id=54-178) —
5 families, each a `50`–`950` scale with hex, HSL and OKLCH values, plus a `primary`/`anchor`
badge marking the reference shade. Rendered live from the `--palette-*` CSS custom properties in
`src/styles/tokens.css`.
